JellyP — Image Optimizer

Preview savings, then optimize internal library artwork in resumable batches. New downloads are processed on subsequent runs. Media-folder artwork, shared files and unsupported images are excluded.

Originals remain in bounded rollback storage. Disk space is released when verified backups are retired. Retiring an original permanently ends rollback for that image.

Jellyfin has no shared image lock. Scans and queued refreshes block changes, but a simultaneous manual upload cannot be excluded. Clear this when maintenance ends.
When unchecked, the temporary original is permanently removed after the image and its reference verify. Existing retained backups remain until explicitly retired.
Use item IDs from Jellyfin details URLs to limit a canary to named items.

Artwork categories

Choose categories and optionally override global encoding settings. People applies to person items before the normal image type. Alpha is always verified exactly against the source at the output size.

Save settings before running. Tasks have no schedule by default; add a schedule under Dashboard → Scheduled Tasks after reviewing the preview.
